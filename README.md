📊 Data Science Tasks

🎯 Objective
This repository contains machine learning projects covering classification, clustering, and time series forecasting:

• Exploring and Visualizing a Simple Dataset - Read, summarize, and visualize a dataset.
• Credit Risk Prediction - Predict loan default probability.
• Customer Churn Prediction - Identify bank customers likely to leave.
• Term Deposit Subscription Prediction - Predict bank customer subscription to term deposit.
• Customer Segmentation - Cluster customers based on spending habits and propose marketing strategies.

🚀 How to Run
1. Clone this repository:
   git clone https://github.com/haris311-creator/data-science-internship-tasks.git
   cd data-science-internship-tasks

2. Install dependencies:
   pip install -r requirements.txt

3. Open notebooks in Jupyter or Google Colab and run cells sequentially.

📋 Task Details:

✅ Task 1: Exploring and Visualizing a Simple Dataset
- Data loading with pandas
- Basic EDA and statistical summary
- Data visualization with matplotlib/seaborn

✅ Task 2: Credit Risk Prediction
- Data cleaning & handling missing values
- Categorical encoding (Label/One-Hot)
- Classification models (Logistic Regression, Random Forest)
- Model evaluation (Confusion Matrix, F1-Score)

✅ Task 3: Customer Churn Prediction
- Feature engineering
- Class imbalance handling
- Feature importance analysis
- Business interpretation of results

✅ Task 4: Term Deposit Subscription Prediction (Bank Marketing)
- Data preprocessing and categorical encoding (Label + One-Hot)
- Classification modeling (Logistic Regression, Random Forest)
- Model evaluation (Accuracy, Precision, Recall, F1-Score, ROC-AUC)
- Explainable AI using SHAP for model interpretability
- Handling imbalanced datasets
- File: Term Deposit Prediction.ipynb

✅ Task 5: Customer Segmentation Using Unsupervised Learning
- Exploratory Data Analysis (EDA)
- K-Means Clustering with Elbow Method for optimal K
- Dimensionality Reduction (PCA, t-SNE) for visualization
- Customer profiling and segment characterization
- Data-driven marketing strategy development
- Files: Customer Segmentation.ipynb, Mall_Customers.csv
