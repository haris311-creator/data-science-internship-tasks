# 📊 Data Science Tasks

## 🎯 Objective
This repository contains three beginner-friendly machine learning projects:
1. **Exploring and Visualizing a Simple Dataset** - Read, summarize, and visualize a dataset.
2. **Credit Risk Prediction** - Predict loan default probability.
3. **Customer Churn Prediction** - Identify bank customers likely to leave.


## 📂 Project Structure
data-science-internship-tasks/
├── Task1_Exploring_and_Visualizing_a_Simple_Dataset.ipynb
├── Task2_Credit_Risk_Prediction.ipynb
├── Task3_Bank_Churn_Prediction.ipynb
├── requirements.txt
└── README.md

## 🚀 How to Run
1. Clone this repository:
```bash
git clone https://github.com/haris311-creator/data-science-internship-tasks.git
cd data-science-internship-tasks

2. Install dependencies:
pip install -r requirements.txt

3. Open notebooks in Jupyter or Google Colab and run cells sequentially.

📥 Datasets: 
Task 2: https://www.kaggle.com/datasets/mosaadhendam/loan-prediction-dataset
Task 3:  https://www.kaggle.com/datasets/shubh0799/churn-modelling?spm=a2ty_o01.29997173.0.0.356855fb8jYVw2

Skills Demonstrated:
- Data cleaning & handling missing values
- Categorical encoding (Label/One-Hot)
- Supervised classification (Random Forest, Logistic Regression)
- Feature importance & Confusion Matrix analysis
- Exploratory Data Analysis (EDA)
